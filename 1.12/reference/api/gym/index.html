    Gym interop¶

    Vectorized Gymnasium-compatible environments over DynaPlex MDPs — see the user guide. Requires the optional gymnasium dependency (pip install "dynaplex[gym]").

    VectorEnv ¶

    VectorEnv(mdp: MDPProtocol, *, features: type, num_envs: int = 256, max_episode_steps: int | None = None, autoreset: bool = True, workers: int = 0, backend: str = 'auto', jit: bool | None = None, max_steps: int = 1 << 20)

    Vectorized Gymnasium environment over a DynaPlex MDP.

    Parameters:

    Name Type Description Default
    mdp MDPProtocol

    the MDP instance. Observations come from features, actions are Discrete(mdp.num_actions) with the validity mask riding in infos["action_mask"].

    		 required
    features type

    the featurizer CLASS (@featurizer-decorated). Observations are BUNDLES: the observation space is a spaces.Dict with one Box per spec tensor (keyed by writer field name), and reset/step return dicts of batched arrays (SB3's CombinedExtractor / gym Dict-space convention).

    		 required
    num_envs int

    number of parallel environments (kernel slots). Hundreds is the intended regime — per-step overhead is per STEP, not per env.

    		 256
    max_episode_steps int | None

    time-based truncation cap in units of context.time_elapsed (None = 2048 for infinite-horizon MDPs, never for finite-horizon ones).

    		 None
    autoreset bool

    True (the default) is same-step autoreset. False — park mode for external collectors with subset reset(env_id) — is not implemented yet.

    		 True
    workers int

    worker worlds of the engine backend. 0 = auto (cpu_count - 2, capped at num_envs). Pure throughput knob: trajectories are worker-count-invariant bit-for-bit.

    		 0
    backend str

    "auto" (default) | "engine" | "python", see module docstring.

    		 'auto'
    jit bool | None

    passed through to Engine (None = auto). Engine backend only.

    		 None
    max_steps int

    per-episode raw-step safety cap (events + actions), guarding MDPs that stall without advancing time or reaching FINAL.

    		 1 << 20

    reset ¶

    reset(seed: int | None = None, options: dict[str, Any] | None = None, env_id: NDArray[np.int_] | None = None) -> tuple[dict[str, np.ndarray], dict[str, Any]]

    Start fresh episodes in every slot and return (observations, infos).

    seed re-derives all episode streams (a later reset(seed=s) with the same s replays byte-identically); without a seed the streams CONTINUE — current episodes are abandoned and each slot starts its next one. env_id (tianshou subset reset) requires park mode (autoreset=False).

    step ¶

    step(actions, ready_env_ids: NDArray[np.int_] | None = None) -> tuple[dict[str, np.ndarray], NDArray[np.float32], NDArray[np.bool_], NDArray[np.bool_], dict[str, Any]]

    Advance every env by one action to its next decision point.

    Rewards are -(cost incurred during the step). On envs whose episode ended this step, the returned observation/mask already belong to the autoreset episode; the end state's features ride in infos["final_observation"] (infos["_final_observation"] marks the rows). ready_env_ids is accepted for tianshou compatibility and ignored (sync env: actions are always full-width).

    close ¶

    close() -> None

    No-op: the engine and its worker worlds are reclaimed with the env.

    seed ¶

    seed(seed: int | None = None) -> None

    Tianshou-style seeding: equivalent to reset(seed=seed).
